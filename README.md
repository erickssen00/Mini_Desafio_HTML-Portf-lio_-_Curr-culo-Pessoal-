# Portfólio Pessoal

Este projeto é uma página de portfólio pessoal desenvolvida em HTML5 durante o curso de Desenvolvimento de Sistemas do SENAI.

## Sobre o projeto

A página apresenta informações pessoais, habilidades, projetos desenvolvidos e uma área para contato.

O projeto foi criado com foco no aprendizado de HTML5 e na utilização de elementos semânticos para organizar o conteúdo.

## Estrutura

O site possui:

* Cabeçalho com nome e foto pessoal
* Menu de navegação
* Seção "Sobre Mim"
* Lista de habilidades
* Tabela com projetos realizados
* Links para os projetos no GitHub
* Formulário de contato
* Rodapé com informações de contato

## Tecnologias utilizadas

* HTML5
* CSS básico através de atributos HTML
* Formulários HTML
* Links
* Tabelas
* Elementos semânticos

## Projetos apresentados

O portfólio apresenta três projetos:

1. Projeto Filme
2. Identidade Itaú
3. Projeto Loja de Jogos

Cada projeto possui informações sobre as tecnologias utilizadas, seu status e um link para o GitHub.

## Formulário de contato

O formulário permite que o visitante informe:

* Nome
* E-mail
* Mensagem

Os dados são enviados através do método `POST` para o arquivo `enviar.php`.

## Objetivo

O objetivo do projeto é praticar a criação de páginas HTML, organização de conteúdo, formulários, tabelas, links e elementos semânticos.
